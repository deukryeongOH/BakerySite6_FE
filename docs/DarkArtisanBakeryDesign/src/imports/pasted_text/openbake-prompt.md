# 만들 것

**오픈베이크(OpenBake)** — 로컬 베이커리 한정판 드롭 커머스 모바일 앱의 인터랙티브 프로토타입.
React 기반, 모바일 뷰포트(375×812) 기준. 총 12개 화면.

## 서비스 개념

동네 베이커리가 **정해진 시각에 정해진 수량만** 파는 한정판 드롭 플랫폼.
나이키 SNKRS의 스니커즈 드롭 방식을 빵에 적용한 것.

**핵심 흐름:**
1. 판매자가 미리 드롭 등록 (예: 7/17 14:00 오픈, 두쫀쿠 30개, 3,000원)
2. 7/17 14:00 정각에 판매 오픈 → 30개가 30초 만에 매진될 수 있음
3. 사용자는 **예치금**(미리 충전한 잔액)으로 결제
4. 결제할 때 **픽업 날짜를 선택** (판매자가 정한 기간 중 하루)
5. 그 날짜에 매장 방문해서 빵 수령

# ⛔ 절대 규칙 — 이걸 어기면 전부 다시 만들어야 함

이 서비스는 일반 커머스와 다릅니다. 아래를 **절대** 만들지 마세요.
일반 커머스 패턴을 자동으로 가져오지 마세요.

1. **배송이 없습니다.** 매장 픽업만 있습니다.
   → 배송지 입력, 주소록, 운송장, 배송 조회, "배송중"/"배송완료" 상태 **전부 금지**
   → 대신 **픽업 날짜**와 **매장 위치**가 그 자리에 들어갑니다

2. **장바구니가 없습니다.** "찜"만 있고, 찜에서는 결제할 수 없습니다.
   → 전체선택 체크박스, 합계 금액, "주문하기" 버튼, 수량 스테퍼 **전부 금지**
   → 결제는 항상 드롭 상세 페이지에서 **단건**으로만

3. **결제 수단 선택이 없습니다.** 예치금 잔액에서만 차감됩니다.
   → 카드 선택, 계좌이체, 간편결제 선택 UI **전부 금지**

4. **리뷰, 별점, 쿠폰, 반품, 교환 화면이 없습니다.**

5. **한 드롭에서 한 사용자는 1회만 주문 가능합니다.** 판매자가 1인당 최대 개수를 정합니다(예: 5개).

# 화면 1 — 메인 홈

일반 커머스처럼 상품 그리드로 만들지 마세요. **드롭 시각별 그룹핑**이 이 서비스의 핵심입니다.

**구성 (위→아래):**

1. **헤더** — 좌측 로고 "오픈베이크", 우측 예치금 잔액 `50,000원` (탭 → 지갑)

2. **히어로 카운트다운 카드** (풀블리드, 액센트 배경)
   ```
   다음 드롭까지
        00 : 13 : 24        ← 모노스페이스, 48px, 흰색
        시     분     초      ← 11px, 반투명 흰색
   오늘 14:00 · 2개 베이커리
   ```

3. **슬롯별 섹션** — 시각이 섹션 헤더
   ```
   ━━━━━━━━━━━━━━━━━━━━
   14:00 드롭          00:13:24
   ━━━━━━━━━━━━━━━━━━━━
   [카드] [카드]  ← 가로 스크롤

   ━━━━━━━━━━━━━━━━━━━━
   17:00 드롭          03:13:24
   ━━━━━━━━━━━━━━━━━━━━
   [카드]

   ━━━━━━━━━━━━━━━━━━━━
   방금 종료
   ━━━━━━━━━━━━━━━━━━━━
   [카드-품절]
   ```

4. **드롭 카드** (폭 148px, 가로 스크롤 아이템)
   ```
   ┌──────────┐
   │ [이미지]  │ ← 정사각, 우상단 상태 뱃지 오버레이
   ├──────────┤
   │ 어니언베이커리 │ ← Caption, muted

   - 품절 카드는 grayscale(1) + 투명도 60%

5. **하단 탭바** — `홈` `찜` `주문내역` `마이` (아이콘 + 라벨)

# 화면 2 — 드롭 상세 ★ 가장 중요

**4가지 상태를 모두 만들어주세요.** (오픈 예정 / 판매중 / 품절 / 종료)

**공통 구성 (위→아래):**

1. **히어로 이미지** — 정사각, 풀블리드
   - 좌상단: 뒤로가기 (반투명 흰 원형 배경)
   - 우상단: 하트 아이콘 (동일 스타일)

2. **상태 뱃지** — 이미지 아래 좌측

3. **타이틀 블록**
   ```
   어니언베이커리          ← Caption, muted
   두쫀쿠                 ← H1
   3,000원                ← H2
   풍긋한 페이스트리에...    ← Body, muted, 2줄
   ```

4. **드롭 정보 카드** (surface 배경, 라벨-값 2열, 우측 정렬)
   ```
   판매 오픈        7/17 (금) 14:00
   판매 마감        7/17 (금) 16:00
   남은 재고        22 / 30        ← 22는 H1 크기 accent, /30은 Caption muted
   1인 구매 제한     5개 (1회 주문만)
   ```
   재고 아래에 **프로그레스 바** (73% 채움, accent 색)

5. **픽업 정보 카드** (surface-warm 배경 — 이게 이 서비스 고유 UI라 시각적으로 구분)
   ```
   📍 픽업 안내                    ← H2

   픽업 기간        7/17(금) ~ 7/23(목)
   픽업 시간        평일 09:00 ~ 18:00
   픽업 장소        어니언베이커리
                   서울 마포구 연남로 12
                   [지도 보기 →]

   ⚠️ 토·일 휴무 · 배송 없음, 매장 방문 수령만 가능
   ```

6. **하단 고정 CTA 바** (sticky, 배경 흰색 + 상단 테두리)

**상태별 차이:**

| | 히어로 오버레이 | 재고 행 | CTA |
| --- | --- | --- | --- |
| **오픈 예정** | 반투명 검정 + 중앙 카운트다운 `02:14:33` (Display, 모노) + 위에 "오픈까지" | `30개 한정` ← **크게 강조**. 이게 드롭의 핵심 정보 | `찜하고 알림받기` (아웃라인) |
| **판매중** | 하단에 얇은 바 `판매 마감까지 01:23:45` | `22 / 30` + 프로그레스 바 | `구매하기` (accent 채움) |
| **품절** | 회색 반투명 + 중앙 `SOLD OUT` 대각선 45도 스탬프 | `0 / 30` | `품절` (disabled) |
| **종료** | 회색 반투명 + 중앙 `판매 종료` | **재고 행 삭제** | `종료된 드롭입니다` (disabled) |

**오픈 예정에도 픽업 정보 카드를 전부 표시할 것.** 사용자가 "갈 수 있는 거리인가"를 판단하고 찜해야 합니다.

# 화면 3 — 주문 페이지 ★★ 가장 독특. 여기 제일 공들일 것

**픽업 날짜 선택**이 이 화면의 핵심입니다. 일반 커머스에 없는 UI라 기존 패턴을 가져오면 안 됩니다.

1. **헤더** — 뒤로가기 + "주문/결제"

2. **주문 상품 카드** — **1건만.** 리스트 아님.
   ```
   [썸네일 72px]  어니언베이커리      ← Caption muted
                 두쫀쿠             ← Body 600
                 3,000원            ← Body

                 [－]  5  [＋]   최대 5개
   ```
   5에서 [＋] 비활성.

3. **픽업 날짜 선택** ← 이 화면에서 가장 크고 눈에 띄게
   ```
   픽업 날짜를 선택해주세요           ← H2
   선택한 날짜에 매장에서 수령합니다     ← Caption muted
   ```

   **달력 위젯 만들지 마세요. 가로 날짜 칩 7개로 만드세요.**
   기간이 7일뿐이라 달력은 과합니다.

   각 칩 (56×72px, 라운드 10px):
   ```
   ┌────┐
   │ 금  │  ← Micro, 위
   │ 17 │  ← H1, 굵게
   └────┘
   ```

   3가지 상태를 명확히:
   - **선택 가능**: 흰 배경, `--border` 1.5px 테두리, 진한 텍스트
   - **선택됨**: `--accent` 채움, 흰 텍스트, 살짝 확대(scale 1.05) + 그림자
   - **휴무**: `--disabled` 배경, 회색 텍스트, **대각선 취소선**, 칩 아래 Micro로 "휴무"

   칩 7개: `17(금)` `18(토)휴무` `19(일)휴무` `20(월)` `21(화)` `22(수)` `23(목)`
   → **20(월)이 선택된 상태**로

   칩 아래 **선택 결과 박스** (surface-warm):
   ```
   ✓ 7월 20일 (월) 방문
     09:00 ~ 18:00 사이 아무 때나 오시면 됩니다
     어니언베이커리 · 서울 마포구 연남로 12
   ```

4. **결제 정보**
   ```
   상품 금액                15,000원
   ────────────────────────────────
   총 결제 금액             15,000원   ← H1
   ```

5. **예치금 블록** (surface-warm)
   ```
   💰 예치금 결제
   현재 잔액                50,000원
   결제 후 잔액             35,000원   ← muted
   ```
   **카드/계좌 선택 UI 절대 금지.**

6. **하단 고정 CTA**: `15,000원 결제하기` (accent 채움, 풀와이드)

**변형 1개 더 만들 것 — 잔액 부족 상태:**
- 예치금 블록 테두리가 accent 색
- `현재 잔액 8,000원` / `7,000원 부족` (accent 텍스트)
- CTA가 `충전하고 결제하기`로 변경

# 화면 4 — 주문 내역 (목록)

1. 헤더 "주문 내역"
2. 필터 탭: `전체` `픽업대기` `구매확정` `취소`
   → **"배송중", "배송완료" 탭 절대 금지**

3. 주문 카드 (4개 정도, 상태 다양하게)
   ```
   ┌────────────────────────────────┐
   │ [픽업대기]           7/17 결제   │
   │ ┌────┐ 어니언베이커리            │
   │ │썸네일│ 두쫀쿠 5개              │
   │ └────┘ 15,000원                │
   │ ──────────────────────────────  │
   │ 📍 7/20 (월) 픽업        D-3    │ ← D-3을 우측에 H2 크기로
   └────────────────────────────────┘
   ```
   - **D-day를 크고 굵게.** 이 앱에서 가장 중요한 정보.
   - D-0이면 accent 색 + `오늘 픽업!`
   - 상태 뱃지 4종: `결제완료` `픽업대기` `구매확정` `취소`
   - **카드 하나는 D-0(오늘 픽업)으로 만들 것**

# 화면 5 — 주문 상세

1. **상태 스텝 인디케이터** (가로, 3단계만)
   ```
   결제완료 ──●── 픽업대기 ──○── 구매확정
   ```
   **배송 단계 절대 금지.**

2. **픽업 안내 카드** — 최상단, 가장 크게. 사용자가 이걸 보러 들어옵니다.
   ```
   📍 7월 20일 (월) 픽업
      D-3                    ← Display 크기, accent

      09:00 ~ 18:00
      어니언베이커리
      서울 마포구 연남로 12

      [지도 보기]  [전화하기]   ← 아웃라인 버튼 2개
   ```

3. **주문 상품** — 썸네일 / 어니언베이커리 / 두쫀쿠 5개 / 15,000원

4. **결제 정보**
   ```
